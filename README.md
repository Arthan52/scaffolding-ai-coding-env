# Scaffolding AI Coding Environment

Prototipe UI website edukasi coding untuk siswa SMK dengan pendekatan scaffolding AI dan faded worked-example.

## Fitur utama
- Landing page edukasi modern
- Dashboard modul pembelajaran
- Halaman latihan code dengan editor mock
- AI tutor yang memberi hint bertahap
- Panel progress siswa

## Cara membuka
Buka file `index.html` langsung di browser, atau jalankan server lokal menggunakan:

```bash
python -m http.server 8000
```

Lalu buka:

```text
http://localhost:8000
```

## Struktur file
- `index.html` — layout utama
- `styles.css` — desain UI dan responsivitas
- `script.js` — simulasi interaksi AI tutor dan validasi jawaban
