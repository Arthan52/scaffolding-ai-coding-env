Perulangan dan Repetisi

Perulangan digunakan ketika kita ingin menjalankan blok program berulang kali berdasarkan kondisi tertentu. Dalam JavaScript, loop for sangat umum dipakai untuk menghitung, mengiterasi array, atau menghasilkan pola.

Contoh lengkap: 
for (let i = 1; i <= 5; i++) {
  console.log("Angka:", i);
}
